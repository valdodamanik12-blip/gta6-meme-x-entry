Meme GTA 6 tentang gamer yang masih menunggu sejak 2013 — janggut memanjang, headset bersarang laba-laba — sementara agen AI-nya yang ceria sudah lebih dulu dibayar dari bounty GTA 6 di make.fun. Program `main.ts` menyerahkan alamat postingan X meme ini lewat `POST.json` ke direktori output grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
